# VA. Living Experience — Briefing Digital de Interiores
### VA Arquitetura e Interiores

Uma solução completa, sofisticada e **100% gratuita** para briefing interativo de interiores com seus clientes, sem necessidade de assinaturas mensais (sem custos de Lovable, Framer ou plataformas pagas).

---

## ✨ Principais Funcionalidades

1. **Portal do Cliente:**
   - Visual sofisticado, minimalista e editorial (estética de alto padrão).
   - Avaliação interativa de imagens por ambiente: **Amei (❤️)**, **Gosto (👍)**, **Neutro (➖)** e **Não quero (✕)**.
   - Suporte a múltiplos moradores (ex: casal vota individualmente, permitindo comparar gostos).
   - Etapas organizadas: Estilos, Paleta de Cores, Salas, Cozinha, Quartos, Banheiros, Closets e Prioridades de Investimento.
   - Otimizado para celular, tablet e computador.

2. **Resumo & Compartilhamento Fácil:**
   - Botão para **enviar resumo direto para o WhatsApp da arquiteta**.
   - Botão para **imprimir ou gerar PDF profissional**.

3. **Painel da Arquiteta (Área Restrita):**
   - Acesso protegido por senha (senha inicial padrão: `va2024`).
   - Tabela de briefings recebidos dos clientes.
   - **Matriz de Sintonia do Casal:** identifica automaticamente onde há consenso e onde há divergência entre os moradores.
   - Backup completo dos dados em arquivo JSON.

---

## 🚀 Como Abrir e Usar Agora Mesmo (Sem Instalar Nada)

Você não precisa instalar Node.js, Python ou qualquer programa:
1. Abra a pasta: `C:\Users\Vidart Arquitetura\.gemini\antigravity\scratch\va-briefing-interiores`
2. Dê **dois cliques no arquivo `index.html`**.
3. O site abrirá instantaneamente no seu navegador favorito (Chrome, Edge, etc.).

---

## 🌐 Como Publicar na Web de Graça (Com Link para Clientes)

Para ter um link público na internet (ex: `va-briefing.netlify.app` ou no seu domínio próprio `briefing.va.com.br`) sem pagar nada:

### Opção 1: Netlify Drop (Mais fácil - 1 minuto, sem código)
1. Acesse: **[app.netlify.com/drop](https://app.netlify.com/drop)**
2. Crie uma conta gratuita.
3. Arraste a pasta `va-briefing-interiores` para a tela do site.
4. Pronto! O Netlify gera um link público na hora (grátis para sempre).

### Opção 2: Vercel ou GitHub Pages
- Ambas oferecem hospedagem estática gratuita de alta velocidade e com certificado de segurança SSL (HTTPS).

### Domínio Próprio (`briefing.va.com.br`)
Se você já possui o domínio da sua empresa, pode apontar um subdomínio para o Netlify ou Vercel sem custo adicional.
